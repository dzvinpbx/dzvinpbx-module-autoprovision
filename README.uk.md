# ModuleAutoprovision

<img src="public/assets/img/logo.png" alt="ModuleAutoprovision" width="160">

Модуль автоматичного налаштування IP-телефонів для Dzvin PBX. Виявляє телефони в локальній мережі через Plug-and-Play (PnP) мультикаст, генерує конфігураційні файли для кожного виробника та віддає їх по HTTP.

> Це форк модуля MikoPBX **ModuleAutoprovision** для Dzvin PBX — див. розділ [Походження](#походження) нижче.

## Можливості

- Автоматичне виявлення й реєстрація телефонів через SIP PnP (мультикаст `224.0.1.75:5060`)
- Генерація конфігурацій для Yealink, Snom, Fanvil, Grandstream і Htek
- Спільна телефонна книга для Yealink (XML) і Grandstream (текст)
- Шаблони із підстановкою змінних (`{SIP_USER_NAME}`, `{SIP_NUM}`, `{SIP_PASS}`)
- Відповідність URI за шаблоном із символом `%` для гнучкої віддачі
- Білий і чорний списки MAC-адрес
- Налаштування кнопок BLF (Busy Lamp Field)
- Додаткові INI-параметри для кожного виробника
- Репозиторій прошивок (HTTP і вбудований TFTP-сервер)
- REST API для віддачі конфігурацій і зображень
- Вбудований службовий SIP-користувач `apv-dzvin-pbx` для першого звернення телефонів після скидання

## Підтримувані телефони

| Виробник | Моделі / примітки |
|---|---|
| **Yealink** | T18P, T19D, T21D, T28P, W52P (DECT) |
| **Snom** | усі моделі з підтримкою PnP |
| **Fanvil** | усі моделі з підтримкою PnP |
| **Grandstream** | конфігурація через шаблони, телефонна книга |
| **Htek** | конфігурація через шаблони |

## Встановлення

### З маркетплейсу Dzvin PBX

1. Відкрийте вебінтерфейс Dzvin PBX.
2. Перейдіть у **Модулі** → **Маркетплейс**.
3. Знайдіть **Автоналаштування телефонів** і натисніть **Встановити**.
4. Після встановлення увімкніть модуль на сторінці **Модулі** → **Встановлені**.

### Ручне встановлення

1. Завантажте останній `.zip`-реліз зі сторінки [Releases](https://github.com/dzvinpbx/dzvinpbx-module-autoprovision/releases).
2. У вебінтерфейсі Dzvin PBX відкрийте **Модулі** → **Встановлені**.
3. Натисніть **Завантажити модуль** і виберіть завантажений архів.
4. Увімкніть модуль після встановлення.

## Як це працює

1. Модуль створює на АТС службовий обліковий запис SIP **apv-dzvin-pbx**.
2. Фоновий процес `WorkerProvisioningServerPnP` слухає мультикаст `224.0.1.75:5060` і відповідає на PnP `SUBSCRIBE` від телефонів.
3. Телефон, скинутий до заводських налаштувань, знаходить АТС у локальній мережі й реєструється як **apv-dzvin-pbx**.
4. Користувач набирає з телефона шаблон автоналаштування (наприклад, `*2*XXX`), де `XXX` — потрібний внутрішній номер.
5. Телефон завантажує свою конфігурацію з `/pbxcore/api/autoprovision-http/...` і повторно реєструється вже під призначеним внутрішнім номером.

## Налаштування

Після ввімкнення модуля відкрийте **Модулі** → **Модуль автоматичного налаштування телефонів**. Сторінка налаштувань має п'ять вкладок (і ще одну для прошивок):

| Вкладка | Призначення |
|---|---|
| **Налаштування телефонів** | Прив'язка співробітників до MAC-адрес і шаблонів |
| **Шаблони налаштувань** | Шаблони конфігурацій із підстановкою змінних |
| **Налаштування URI** | Зіставлення URI-шаблонів із шаблонами конфігурацій (символ `%`) |
| **Телефонна книга** | Адреси зовнішніх АТС для спільної телефонної книги |
| **Налаштування PnP** | Шаблон номера, адреса АТС, списки MAC, додаткові параметри |
| **Прошивки** | Файли прошивок, які АТС віддає телефонам |

### Змінні шаблонів

У будь-якому шаблоні можна використовувати:

- `{SIP_USER_NAME}` — ім'я співробітника
- `{SIP_NUM}` — внутрішній номер
- `{SIP_PASS}` — SIP-пароль
- `{PBX_HOST}` — адреса АТС з налаштувань PnP
- `{FIRMWARE_URL}` — адреса завантаження прошивки (якщо її додано у вкладці «Прошивки»)

### Регіональні налаштування телефонів

Модуль сам не задає мову, часовий пояс і NTP-сервер телефонів — це можна зробити в шаблоні або в
додаткових параметрах. Приклад для Yealink (закоментований у вбудованому шаблоні; назви параметрів
залежать від моделі й прошивки):

```
local_time.time_zone = +2
local_time.time_zone_name = Ukraine(Kyiv)
local_time.summer_time = 2
local_time.ntp_server1 = pool.ntp.org
lang.gui = Ukrainian
```

Мова службового SIP-користувача `apv-dzvin-pbx` береться з мови АТС.

## REST API

### Внутрішні (з автентифікацією)

| Метод | Кінцева точка | Опис |
|---|---|---|
| GET | `/pbxcore/api/autoprovision/getcfg?mac=<MAC>` | Згенерувати й віддати конфігурацію для вказаної MAC-адреси |
| GET | `/pbxcore/api/autoprovision/getimg?file=<name>` | Віддати зображення з `assets/img/` |

### Публічні (без автентифікації, для телефонів)

Базовий шлях: `/pbxcore/api/autoprovision-http`

| Кінцева точка | Опис |
|---|---|
| `/{p1}/{p2}/.../{p35}` | Віддача конфігурації за URI-шаблоном (виробник визначається за `User-Agent` / MAC) |
| `/phonebook`, `/yealink` | Телефонна книга у форматі Yealink XML |
| `/grandstream` | Телефонна книга у форматі Grandstream (текст) |
